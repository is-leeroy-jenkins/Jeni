    Gemini Wrappers API¶

    Purpose¶

    This page documents the Gemini provider wrapper module used by Jeni.

    Responsibilities¶

    The Gemini wrapper module is responsible for provider-facing workflows, including text generation, image generation and analysis, image editing, embeddings, audio transcription, audio translation, text-to-speech, Gemini Files API operations, file-search stores, and Google Cloud bucket workflows.

    Import Requirements¶

    This API page imports gemini.py. Build the documentation from the repository root after installing both application and documentation dependencies:

    pip install -r requirements.txt
pip install -r requirements-docs.txt
mkdocs build --strict

    API Reference¶

    gemini ¶

    Gemini provider wrappers for the Jeni Streamlit application.

    Purpose

    Provides application-facing wrapper classes for Gemini text generation, image generation and analysis, embeddings, transcription, translation, text-to-speech, Gemini file operations, file-search stores, and Google Cloud Storage bucket workflows.

    The module centralizes provider request construction, option lists, response extraction, and error logging so the Streamlit application can call stable Python interfaces instead of provider-specific SDK objects directly.
